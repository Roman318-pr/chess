# Шахматы с картами — онлайн

## Запуск на своём компьютере
    npm install
    npm start        # откройте http://localhost:3000

Чтобы друзья из интернета зашли на ваш компьютер, можно временно пробросить порт:
`npx localtunnel --port 3000` (или cloudflared / ngrok) и отправить им выданную ссылку.

## Постоянный хостинг (Render.com, бесплатный план)
1. Загрузите папку на GitHub (новый репозиторий).
2. На render.com: New → Web Service → выберите репозиторий.
3. Build Command: `npm install`  ·  Start Command: `npm start`  ·  Plan: Free.
4. После деплоя получите ссылку вида https://имя.onrender.com — это и есть сайт игры.
Бесплатный план «засыпает» после ~15 минут без посетителей, первая загрузка тогда занимает до минуты.
Подойдут и Railway, Fly.io, любой VPS с Node.js 18+ (WebSocket работает на том же порту, что и сайт).

## Как играть
В меню «Новая партия» → «Создать комнату» → отправьте другу ссылку (или 4-буквенный код).
Сервер сам проверяет все ходы и карты, руку соперника он вам не присылает.
